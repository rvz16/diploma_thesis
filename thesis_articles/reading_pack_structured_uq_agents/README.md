# Reading pack: structured output, uncertainty, and multi-step LLM agents

Russian synthesis of the papers and completed experiments:
[`research_summary_ru.md`](../../research_summary_ru.md).

The files are numbered in the recommended reading order at the time they were
added. Items 01--08 cover trajectory-level agent UQ and propagation; 09--12
extend agent calibration; 13--19 cover the project's central bridge from
structured/constrained generation to function-call risk and intervention;
20--22 are supporting work on action--belief alignment and information
seeking.
